## Правило evidence

После каждого запуска, ревью, просмотра снимков или запроса добавить запись в свой progress: время, ID задачи, база/modified paths, действие, exit/result, ссылка на лог/PNG, вывод, остаток и следующий шаг. `PASS` только при измеренном результате. `SKIP`, `UNKNOWN`, `BLOCKED` не становятся зелёными. Для visual PASS требуется открытый и просмотренный снимок, а не существующий PNG-файл. Доказательства в Git не содержат тексты личной истории, секреты или raw env.

## Условие готовности

Функциональные и визуальные сценарии пройдены на собранном приложении; DMG проходит установку через Applications; пользовательские данные сохраняются; тестовые процессы/volumes/профили убраны; публичная подпись и GitHub artifact проверены отдельно. Если внешнее условие недоступно, записывается точный blocker, а не заявление «готово вообще».
