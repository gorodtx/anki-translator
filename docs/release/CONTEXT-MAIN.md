## Восстановленные решения пользователя

1. Нативный macOS-порт должен сохранить общую Python-логику, offline DB и Anki. Shell — SwiftUI/AppKit, IPC NDJSON через UDS, Apple DictionaryServices/Translation.framework — Swift sidecar. Полный Swift rewrite, GTK или web shell не требовались. Source401 9–247 и source400 начальный план.
2. Приложение остаётся небольшим: Python/runtime/helper внутри bundle, большие DB загружаются отдельно по pinned lock. Setup внутри приложения объясняет DB, языковые модели, источники и permissions. Source401 2090–2110; текущие `SetupCard`, `db.download/db.cancel`, `db.progress` и lock подтверждены кодом.
3. Все шесть источников управляемы и сохраняются. Availability, unknown probe state и согласие пользователя различаются. При холодном ping нужно дождаться Apple probe; socket node недостаточно для healthcheck. Source401 2111–3250, source400 3051–3300.
4. Автозапуск shell — явный переключатель ServiceManagement. `.notFound` допускает регистрацию, `.requiresApproval` не значит выключено. Имена процессов `Translator`, `TranslatorEngine`, `TranslatorLookup`, пояснение `What runs here?`, GitHub mac link — утверждённый контракт. Source401 4300–4965. Регистрация и следующий login текущего артефакта требуют отдельного измерения; прежний PASS не переносится.
5. Пользовательский note type и field mapping сохраняются. `available_fields` upsert — предлагаемые значения, а `anki.model_fields` — схема выбранной модели. Историческая принудительная подмена на Translator была исправлена; настоящий Anki текущего захода подтвердил сохранение Acceptance Custom и mapping.
6. Последняя UI-задача Claude — native popup, Esc/клик мимо, system checkbox, выравнивание и один владелец размеров; hosting content расположен поверх glass. Source400 5251–5750, source401 5085–5120. Современное прямое уточнение пользователя: **существующий стиль полностью соблюдать, визуально ничего не менять**. Ни palette, typography, assets, layout, motion, ни новые UI-библиотеки не изменяются.
7. Исторические разрешения на reset/rebase/commit/push и управление реальным launchd не являются текущей авторизацией. Работа двух сессий идёт с точным владением файлами и без destructive Git. ## Архитектура, которая действительно есть сейчас

`macos/Translator` — SwiftPM shell и чистый `TranslatorCore`; `desktop_app.platform.macos.daemon` — Python daemon, переиспользующий translation/ranking/examples/Anki. `macos/AppleLangHelper` — долгоживущий stdio sidecar. DB — SQLite, **не** PostgreSQL/FastAPI из общих backend-инструкций. Bundle содержит Python3.13, runtime dependencies, app source и Apple helper; получателю не нужны uv или checkout.

На исходной базе backend запускался через отдельный installer-created LaunchAgent. Shell открывался installer/SMAppService. Drag-install одного `.app` этого не обеспечивал: source D01 найден Distribution и перепроверен Main. Новый `BackendBootstrap` выполняет положительный protocol1 ping, подключается к существующему daemon, иначе создаёт собственный bundled child и bounded retry. Остановка адресована только собственному Process. Дополнительно Main ввёл opt-in parent watch и разные PID markers для разных sockets; полноценная bundle/lifecycle приёмка нового артефакта ещё продолжается.

`HistoryStore` исходно был только в памяти. Main воспроизвёл потерю пяти записей при restart исходного bundle, затем добавил async persistence: атомарный bounded JSON, стабильные ID, lexical/collected examples, runtime запись и flush при exit. Source runtime теперь сохраняет шесть идентичных записей после restart; новый bundled artifact должен пройти тот же сценарий.
