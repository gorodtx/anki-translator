## Архитектура и актуальная сверка

`macos/Translator` — SwiftPM native shell; `TranslatorCore` — протокол, ordering, setup, геометрия, тестируемые решения. Shell говорит NDJSON по UDS с `desktop_app.platform.macos.daemon`; Python переиспользует pipeline, ranking, example selection и Anki-логику. `apple-lang-helper` — долгоживущий Swift sidecar на stdio для DictionaryServices и Translation.framework. В bundle Python 3.13 и runtime-зависимости, исходники движка, helper, lock БД и исходная иконка; внешние Python/uv нужны сборщику, не получателю.

Текущий аудит source на `c7ff962` подтверждает:

- `apple_dcs.translation_candidates` — один общий очиститель; `apple.focus_on_query` исключает чужие phrasal blocks; лимит sidecar строки `8 << 20`. Исторические исправления падежных пометок/скобок/85 KB ответа не потеряны.
- `IpcServer.stop` закрывает/обрывает клиентов при остановке; постоянный reconnect и `ReplyOrdering` есть в native коде. Зависание SIGTERM с idle client было исторически исправлено, но текущий runtime требует отдельного запуска.
- `TRANSLATOR_DB_DIR` авторитетен, `ping.db.sources` пофайловый, `pending_bytes` отдельно; `db.download`/`db.cancel` и `db.progress` реализованы. Setup предлагает загрузку, цена считается по отсутствующим файлам. Состояние unknown не равно missing.
- `SourceToggles.any_enabled` и explicit gates есть; Anki model fields берутся через `anki.model_fields`, а `available_fields` в upsert — список предлагаемых записей, **не** схема модели.
- `LoginItem.swift` использует ServiceManagement; `.notFound/.notRegistered` разрешают включение. Переключатель/короткое объяснение процессов уже реализованы, новые библиотеки не нужны.
